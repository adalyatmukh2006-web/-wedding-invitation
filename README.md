# Свадебное приглашение — Руслан и Дарина

Готовый статический сайт для GitHub Pages.

## Публикация
1. Создайте репозиторий на GitHub.
2. Загрузите в него **все файлы из этой папки**, включая `index.html`, фотографии и `.nojekyll`.
3. Откройте Settings → Pages.
4. В Build and deployment выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`.
5. Сохраните. После публикации GitHub Pages покажет адрес сайта.

Важно: загружать нужно содержимое папки, а не ZIP-файл внутри репозитория.
